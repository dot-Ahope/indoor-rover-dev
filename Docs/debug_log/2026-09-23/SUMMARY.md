## §17 목표 도착 heading — "정면보다 살짝 오른쪽" 확인 (n62a~c bag)

질문: 목표(yaw = 출발 map yaw ≈ 0°)에 도착해 오른쪽으로 1~2° 틀어져 멈춘 것이 EKF 도 알고 허용 범위라 승인된 것인가.
방법: Nav2 로그 "Reached the goal!" 시각에서 bag 의 map yaw(SLAM)·odom yaw(EKF) 시계열(`jobs/job552_goalyaw.py`, `jobs/job553_yawseries.py`, 원문 `outputs/j552_goalyaw.txt`, `outputs/j553_yawseries.txt`). 음수 = 오른쪽.

| 주행 | 도달 판정 순간 map | 그때 지령 ω | 정지 후 map | 정지 후 EKF |
|---|---|---|---|---|
| n62a | −7.5° | +0.23 rad/s(왼쪽으로 도는 중) | **−4.0°** | −2.4° |
| n62b | 판정 불가 — 이 주행은 CPU 422 % 로 bag 의 /tf 가 2 s 늦고 띄엄띄엄 기록됨 | | (−15° 로 보이나 신뢰 불가) | |

해석(측정):
- 목표 판정기 `SimpleGoalChecker`(stateful) `yaw_goal_tolerance 0.15 rad = 8.6°`. 로버는 상자를 오른쪽으로 비켜 온 뒤 왼쪽으로 돌며 0° 로 돌아오는데, 오른쪽에서 **허용 띠(±8.6°) 가장자리에 들어서는 순간(−7.5·−8.0°) 성공 판정 → 정지 지령**, 관성으로 1~3° 더 돌고 멈춘다. 그래서 항상 오른쪽으로 남는다(계통적).
- EKF 도 같은 방향·비슷한 크기로 알고 있다(map 과 차이 = map→odom 보정 0.8~1.6°).
- **명시적으로 "승인"한 기준은 없었다** — 게이트·판정 기준(성공·중단·여유·CPU)에 최종 heading 항목이 없었고, 8.6° 는 Nav2 설정값이 허용한 것이다.
- 사용자 목측 1~2° 와 측정 4~7° 의 차는 측정(SLAM) 쪽을 기록으로 삼는다. 출발 자세 자체의 눈대중 기준 차이일 수 있으나 확인 안 됨(추정).

선택지(결정 대기): 허용 0.15 → 0.05 rad(2.9°)면 정지 후 오차가 줄 것으로 예상되나, 스키드스티어 저속 회전 데드밴드로 목표 부근 진동·시간 증가 가능 — F0 왕복에서 복귀 heading 을 재 보고 필요하면 A/B.

- **H1 기각**: 궤적 y 최소 ≤ 0.22(f0a1 수준) 또는 여유 < 0.06 m — 비킬 거리가 아닌 다른 원인.
- 그 사이: 판정 보류(1 회로 결론 내지 않음).
- 부수: 왕복 성공 여부(F1), 목표 1 도착 자세, 복귀 오차는 기록만.

### §20.1 f0a2 결과 — 판정 불가 (복귀 구간에 도달 못 함)

### §20.2 정정 — SLAM 이 맞았다 (줄자 측정)

측정(사용자, 줄자): 출발 테이프(출발 때 로버 오른쪽 트랙 바깥 끝 선)를 진행 방향으로 연장한 선에서, 뒤돌아 선 로버의 왼쪽 트랙 바깥 끝까지 **약 25 cm**(출발 때 로버가 있던 쪽으로). 연장선 방향 오차 1~2° 면 ±4~8 cm.
→ 로버 중심 y ≈ −0.165 + 0.25 + 0.165 ≈ **+0.25 m**. 예상값 EKF ≈ +0.04(선에서 3~4 cm), SLAM ≈ +0.20(선에서 20 cm) 중 **SLAM 쪽**. §20.1 의 "SLAM 스캔 정합 실패" 추정은 **기각**.

정정된 해석: 로버는 제자리 180° 회전 중 실제로 옆으로 약 0.2 m 밀려났고, 휠 오도·자이로(EKF)는 이것을 볼 수 없다(휠 오도는 차체 중심 회전을 가정, vy = 0). SLAM 이 스캔으로 이 이동을 찾아 map→odom 을 0.20 m 보정한 것이다.
- 기하 근거(계산): 한쪽 트랙(중심에서 0.145 m)을 축으로 180° 돌면 중심이 0.29 m 옮겨진다. 시계 방향 회전에서 +y 로 옮겨졌다면 **왼쪽 트랙 쪽이 축**(왼쪽 트랙이 덜 미끄러짐)인 경우와 방향이 맞다. 축 위치는 추정.
- f0a1 의 회전(map→odom +0.06 m)도 같은 현상의 작은 판일 수 있다(미검증).

의미:
1. 제자리 회전 = 스키드스티어에서 중심이 수~수십 cm 옮겨지는 동작. EKF 만 믿는 분석·게이트는 회전 뒤 위치를 틀린다. SLAM 이 있으면 map 좌표는 맞다.
2. 목표에서 0.206 m 떨어진 뒤 MPPI 가 50 s 동안 지령 ≈0 — 목표가 로버 **옆**(뒤돌아 선 로버의 왼쪽 0.2 m)에 있어 스키드스티어는 돌아서 다시 가야 하는데, 목표 근처에서 그런 궤적을 고르지 못한 것으로 보인다(미확인, 뒤쪽 0.4 m 에 물체). 다음 세션 과제.
3. 원인 1 검증은 여전히 미판정.
