nvblox 이전 — 기능은 통과, CPU 는 제자리

로컬·전역 코스트맵의 카메라 층을 STVL 에서 nvblox 로 옮기는 Phase N 을 마쳤다. 같은 상자 회피 코스에서 기준선(STVL) 대비 회피 여유와 상자 기억은 좋아졌고, CPU 합은 줄지 않았다. 아래는 오늘(N6-2)의 판정과 그 과정에서 확인한 사실들이다.

얻은 것

  • 회피 여유 증가 — 전역에도 상자가 들어가 원경로 자체가 넓어졌다.
  • 상자 뒤까지 기억하고 모양이 물리에 가깝다(절단 2.0, 감쇠 0.99 → 81 s).
  • 근거리 사각(0.45 m 안) 제거 — 정지 게이트 기준.
  • 3D·GPU 경로 확보 — 동적 객체(N7)·cuVSLAM 의 기반.

잃은 것 · 남은 과제

  • CPU 절감 기대(≥ 30 %p) 미달성 — 릴레이 −15, nvblox +18 로 상쇄.
  • 반사성 바닥 테이프 위 유령 치명 셀 — 테이프를 치우니 0. 강건성 과제 R1.
  • 컨테이너·포크(round→floor) 유지 비용.
  • 점군 끄기(−6 %p)는 게이트·러너가 점군을 써서 시험 중 불가.
