- **지도를 조금씩 넓혀가기**: 가능 — 세션마다 slam_toolbox 포즈 그래프 저장(`serialize_map`), 다음 세션에 `map_file_name` + `map_start_pose`(출발 테이프)로 이어 그리기. 위험: 시작 자세 어긋남 → 이중 벽, 그날의 물체가 영구 장애물로 남음, Humble 2.6 "이어 그리기" 는 기본 매핑보다 덜 검증(우리 포크는 스캔 처리 조건만 바꿔 영향 없을 것으로 추정 — 미확인). 대책: 항상 출발 테이프에서 시작·첫 스캔 겹침 ≤ 5 cm 확인, 첫 확장에서 벽 겹침·출발점 오차 측정.

## §2 지도↔줄자 앞뒤 편차(+3.6/+5.5/+5.2 cm, 09-29 §12.5) 원인 확인 — 1 차
- 사용자 실측: **라이다 중심 → 뒤쪽 트랙 끝 ≈ 0.40 m**. URDF lidar_joint x = +0.152 → 뒤끝 = base_link −0.248 m. 계산에 쓴 −0.25(Nav2 footprint 와 같음)와 2 mm 차 → **뒤·왼 모서리 가정은 맞음**, 편차 원인 아님.
- 남은 후보: 출발 표시(오른쪽 트랙 앞끝) 위치를 base_link +0.25(차체 0.50 m 가정)로 둔 것. 실제 앞끝이 +0.30 이면 예측 세로가 5 cm 줄어 세 번의 편차가 거의 설명됨(계산). → **라이다 중심 → 앞쪽 트랙 끝** 실측 요청.
