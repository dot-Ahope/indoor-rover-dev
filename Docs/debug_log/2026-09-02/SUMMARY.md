- **평상시 직진 성능 양호**: 대체로 0.1~0.4°/m (1m당 0.4° 이내). Nav2 컨트롤러가 흡수 가능한 수준.
- 부수 성과: **회전 감속 로직(목표 15° 전 ω×0.35)으로 회전 정확도 91~93°** (이전 98~107°).

### ⚠ 진단 한계 — 휠별 텔레메트리 부재 (중요)

## B-1 — 회전이 필요한 목표 (180° 회전 후 0.5m) ✅

### 1차 시도 — 실패: 100초간 정지 후 recovery만 동작
- 증상: 목표 수락 후 **~100초간 로버가 전혀 안 움직임**, 그 뒤 갑자기 회전.
- 로그: `Failed to make progress` → `Aborting handle` → `behavior_server: Running spin (Turning 1.57)` 반복.
  → **회전시킨 주체는 컨트롤러가 아니라 `spin` 복구 동작**이었음.

### 원인 ①(부분) — progress checker 가 회전을 진행으로 안 봄
- `SimpleProgressChecker` 는 **병진만** 진행으로 인정 → 제자리 회전이 필요한 목표에서 `movement_time_allowance` 마다 중단·재시도.
- **수정: `nav2_controller::PoseProgressChecker`** (+`required_movement_angle: 0.5`) → 회전도 진행으로 인정.
- 단, 이것만으로는 해결되지 않았음(정지 지속) → 진짜 원인은 아래.

### 원인 ②(핵심) — RPP 각가속 클램프 + 로버 기동 데드밴드 = 데드락 ⭐
`/cmd_vel_nav`(RPP 출력)와 `/cmd_vel`(스무더 출력)를 동시 모니터해 확정:
```
RPP 출력:  v=+0.000, w=+0.050 rad/s  (68초 내내 일정)
스무더:    동일 (체인 정상, 값 그대로 전달)
로버 heading: 176.9° → 176.4°  (전혀 안 돎)
```
- RPP `rotateToHeading()` 은 각속도를 **`현재 측정속도 ± max_angular_accel × dt`** 로 클램프.
- `max_angular_accel: 1.0`, 제어주기 20Hz(dt=0.05) → **첫 명령 상한 0.05 rad/s**.
- 0.05 rad/s = 휠 속도 ±6mm/s → **정지마찰·PWM 데드밴드 이하라 로버가 안 움직임** → 측정속도 0 유지 →
  다음 사이클도 0.05 → **영구 데드락**.
- 직진 목표가 성공했던 이유: **RPP 는 선형 속도엔 이 가속 클램프를 적용하지 않음**.

|---|---|---|---|

### 판단
- **RPP 0/1, MPPI 0/2. 공통 근본 원인 = 기동 데드밴드.**
  - RPP: 회전 시작 데드락(기수정) + 좁은 공간 기동력 한계
  - MPPI: 후진·통과 능력은 우수하나, **미세 명령이 무반응 구간에 갇혀** 목표 근접 정체·중간 배회
- 임시 우회(`xy_goal_tolerance` 0.15→0.25)는 목표 근접 정체만 완화 — 중간 배회는 불변. **컨트롤러 튜닝으로 해결 불가.**
- **결론: N1 게이트는 펌웨어 데드밴드 보상 플래시 후에만 통과 가능.** MPPI 우세 경향(후진·통과)은 확인됨 — 플래시 후 재벤치마크로 확정.

### 펌웨어 수정 완료 (소스만, 플래시 대기) ⭐

  - 규칙: |v|<EPS → 0 (정지 의도 유지), EPS≤|v|<MIN → MIN 으로 승격(부호 보존)

  1. ω=0.05 rad/s 명령에 로버가 실제로 회전하는지 확인 (데드락 재현 테스트)
