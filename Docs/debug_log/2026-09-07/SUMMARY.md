## 판단
- 트랙이 물리적으로 서 있어도 펌웨어는 좌측 휠 속도를 ~0.02 m/s 로 보고 → 600ms 창에 ~12mm 이동으로 계산 → 스톨 판정(3mm 미만) 통과 불가.
- 원인(코드 확인): FG 펄스는 방향 정보가 없고 `bldc_last_dir_sign()` 으로 지령 부호를 주입 (`fg_encoder_driver.c:125,144`). 구속된 모터가 진동/정류 스텝을 밟으면 그 펄스가 전부 "전진"으로 누적됨. 엔코더가 모터축(기어 1:90 앞단)이라 백래시 내 흔들림도 펄스가 됨.
- 따라서 **FG 이동거리 기반 스톨 감지는 하드 구속을 못 잡는다** (지령 문턱이든 duty 문턱이든 동일). 09-03 Nav2 스톨 래치는 낮은 duty·마찰 부하에서 조용히 선 경우로 추정(진동 펄스 적음) — 미검증.
- 보드에 모터 전류 측정 경로 없음(`/battery.current = NAN`, 션트 없음).
- 활용 가능한 신호: FG 캡처가 1µs tick 주기(`s_period`)를 보관 → 펄스 주기 규칙성/duty 대비 펄스율 독립성으로 "가짜 회전" 판별 가능성 있음(데이터 필요).

## 결론 (측정 기반)
1. **구속 상태에서도 FG 펄스가 난다.** 정지 휠에서 펄스 주기 = PWM 주기 20.0ms(50Hz) 정확히, 폭 10~21ms의 정상 논리 펄스. 진동(사용자 관찰)과 함께 발생 → 드라이버가 50Hz로 강제 정류하고 회전자가 못 따라와도 펄스는 나오는 것으로 해석(추정). 펄스폭·주기 규칙성으로는 자유 회전과 구분 불가(자유 저속도 20.0ms·cv 낮음 구간 존재).
2. 그 펄스는 **속도 15mm/s(=50pps)** 로 환산되어 승격값 0.020 목표를 거의 만족 → 적분이 안 쌓여 duty 55~70%에서 정체. 구속이 지속돼도 감지 불가, 모터는 계속 웅웅거림. 지령 ≥0.03이면 적분이 98%까지 오름.
3. **하드 잼(펄스 0)** 은 600ms 내 감지·자동복구 됨(Run F). 드라이버 자체 보호 여부는 이번에도 확인 못 함(펄스 0 = 순간 완전 고정과 구분 불가).
4. **오도메트리 함의**: 저duty 정체 휠이 15mm/s 로 누적됨 → 선회 중 안쪽 휠 정체 시 오도메트리 오차원. 09-02 스케일 1.2786 의 일부가 이 기저 펄스일 가능성(미검증, 속도별 스케일 비교 필요).
5. **미해결 이상**: 오늘 받침대에서 0.05 m/s 유지에 duty 93% 필요(08-26: 98%→0.115 m/s). 배터리 12.2V. 원인 미상 — 바닥 최고속 재측정 필요.
