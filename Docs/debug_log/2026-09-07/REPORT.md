# WT-600 재캘리브레이션 보고 — 2026-09-07

> 스톨 보호 정책을 검증하려던 하루가 모터 구동 주파수 오류, 휠 상수 오류, 회전 모델 부재라는 세 가지 근본 원인을 차례로 드러냈다.

## 1. 추론 흐름
1. **스톨 정책 받침대 검증 → 검출 없음.** 트랙을 고정해도 펌웨어가 좌측 휠 14~28 mm/s 보고. 가설: FG 는 방향이 없어(`bldc_last_dir_sign` 주입) 떨림도 전진 누적. → 휠별 텔레메트리(duty·pps·주기·CV·폭) 추가.
2. **서명: 구속 펄스 주기가 정확히 20.0 / 10.0 ms** (PWM 50 Hz 와 2배). 폭 10~21 ms 정상 펄스 → 누화 기각. 기각한 대안: 펄스폭 필터, 주기 규칙성 기준, 승격값 0.030(100 Hz 모드와 겹침).
3. **근본 원인: `MOTOR_1TO90_MIGRATION_PLAN.md` §3.1 미적용.** 신규 모터 권장 15~25 kHz 인데 드라이버는 구모터 50 Hz. 20 kHz 전환 → 구속 휠 pps 0 → 스톨 2.4/5.2/7.8 s 하드 래치. 자유 휠 10~100 mm/s 정확 추종, duty ≈ 0.36 + 4.5·v.
4. **바닥 재실측.** 데드밴드 소멸(10 mm/s 추종). 라이다 벽 변위 GT 3회: 원시/실 = 1.297/1.275/1.289 → 속도 무관 = 상수 오류. 0.16130/1.2870 = 0.12533 (공칭 Ø40 과 0.3 %). 교정+`VX_SCALE` 1.0 동시 배포 → 재주행 1.0006.
5. **회전.** D455f 프레임에서 로버 요는 **y 축**(z 적분은 ≈0). 자이로 기준 SLIP 0.600 → 유효 게이지 B_eff 0.409 → 재측정 중앙값 **0.443**. 잔여 ±15 % 는 바닥 의존(표준오차 2.8 % 안 → 반복 중단).
6. **벤치마크 → RPP.** MPPI 실패 원인: ①제자리 회전 부재(U턴 호 반경 0.21 m → 횡변위 0.31~0.32 m) ②목표 0.4 m 이내 경로 크리틱 OFF ③직사각 풋프린트 회전 봉쇄 ④지평 12.8 cm ⑤노이즈 클리핑 ⑥CPU 기각(20 Hz 유지, 미달 3/5400).
7. **사고 대응.** 벽 긁힘 중 휠은 계속 돌아 펌웨어·EKF 모두 "이동 중" → 휠 무관 관측(스캔 상관·섹터 range·자이로)의 `stuck_monitor.py` shadow 배포. 자체시험 통과, RPP 46 s 오탐 0.

## 3. 결과 (핵심)
- 받침대 서명: 50 Hz 구속 → pps 40~100, T 20.0/10.0 ms 고정, 감지 없음(94 % 이상에서만 펄스 소실). **20 kHz 구속 → pps 0, 2.4/5.2/7.8 s 래치.** 자유 0.04 → pps 150~184, CV 0~1 %.
- 20 kHz 곡선: 10/20/30/50/100 mm/s → duty 40/45/49/58/81 %, 전부 1 s 내 정확 추종.
- 직진: 교정 전 1.297/1.275/1.289 → 교정 후 **1.0006**.
- 회전: B_actual 13회 0.429 ± 0.044; B=0.443 에서 휠/자이로 0.82~1.15(평균 0.93). ω 0.40 은 휠 포화 → 실 상한 0.384.
- 벤치마크: RPP 19.7 / 25.1 / 10.7 s 성공, 반전 0. MPPI 150.6 / 120.6 s 타임아웃, |v| 평균 0.016~0.018, 반전 21/7. 검증 55a/b: inflation 0.35 에서도 19.7 / 26.3 s, stuck shadow 오탐 0.

## 4. 분석
- **층을 벗겨 내려간 원인 규명**: 증상 → 펄스 → 주기 → PWM 설정. 각 층에서 대안 가설을 측정으로 기각. 최종 원인은 코드가 아니라 문서와 코드의 불일치.
- **측정과 추정의 분리**: 모든 상수에 GT 명시(둘레 = 라이다 3회, 게이지 = 자이로 13회, 컨트롤러 = 동일 코스 7회).
- **동시 배포 규율**로 교정의 소재가 한 곳에 수렴 → 직진·회전·지령 3축 일치.
- **실패의 정량화**: MPPI 원인 6개에 신뢰도 부여. 횡변위 0.31~0.32 m 가 최소 회전반경 0.21 m 기하로 설명됨.
- 한계: 회전 오도 ±15 %(바닥 의존), 스캔 정합 GT 잔차 17~22 cm, stuck_monitor 정탐 미검증·개활지 무력, MPPI 는 이 속도 영역 밖, 드라이버 과전류 사양 미확인, UART5 배선 없음.
