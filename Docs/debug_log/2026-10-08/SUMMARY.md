# 2026-10-08 — 전역 카메라 기억: nvblox 로 풀 수 있나 (STVL 정리 검토)

전날 기록: `Docs/debug_log/2026-10-07/SUMMARY.md` §8(전역 카메라 STVL 시험: C1 통과·C2 불합격), §10(계획기·MPPI 지도 불일치), §16(STVL 제거 검토 질의).

## §1 nvblox 슬라이스로 C1·C2 확인 — 선언(사용자: 다음 단계 진행)
- 배경: 기본 구성엔 STVL 이 이미 없음(로컬 nvblox + 라이다, 전역 정적 + 라이다·카메라 점군 obstacle). 쟁점은 전역 카메라 기억(사용자 조건: 화각 밖은 기억, 카메라가 볼 때는 갱신)을 STVL 대신 이미 도는 nvblox 로 풀 수 있는가.
- 자료: 10-07 상자 시험 녹화 `bags/bag_box1.tgz`(카메라 점군·nvblox 슬라이스 `/nvblox_node/static_map_slice`·TF 포함). 로버 안 움직임(재생·분석만).
- 방법(`jobs/job933_nvslice.py`): 2 s 마다 상자 ② 자리(map x 1.05~1.35 · y −0.30~+0.10, 칸 중심 48 개)를 슬라이스 좌표(odom)로 옮겨 거리 ≤ 0.05 m 인 칸 수.
- 판정(어제 STVL 과 같은 기준):
  - C1 기억: 0.35 m 앞까지 다가간 30 s 동안 상자 칸 ≥ 정지 기준값의 50 %.
  - C2 갱신: 치운 뒤(카메라 점 100 → 0, 14:10:16 무렵) 5 s 안에 0.
  - 참고: 감쇠(0.99·5 Hz ≈ 81 s)로 지워졌다면 '본 것' 이 아니라 '시간' 으로 지운 것 — 치운 순간과 사라진 순간의 간격으로 가른다.
- Jetson 무응답(172.30.1.8·192.168.0.101 ping 0) → PC 에서 분석: `rosbags` 로 bag 을 읽고 nvblox_msgs/DistanceMapSlice 정의(header·resolution·width·height·origin·unknown_value·data)를 직접 등록. 검증: 모든 슬라이스에서 data 길이 = width×height(불일치 0). `jobs/nvslice_pc.py` → `outputs/nvslice_box1.txt`.

- C1 기억: **통과**(가까이서 17~21 ≥ 기준 9 의 50 %). 단 30 s 유지는 감쇠 수명(≈ 81 s) 안이라 '오래 기억' 의 근거는 아님.
- C2 갱신: 선언 기준(5 s 안에 0)으로는 **불합격** — 8 칸 중 6 칸(75 %)은 3 s 안에 지워졌지만 1~2 칸이 64 s 남음. 남은 칸이 '본 것' 으로 지워졌는지 감쇠로 지워졌는지는 이 자료로 못 가름(감쇠 81 s 와 비슷한 시간).
- STVL 과의 차이(측정): STVL 은 치운 뒤 0 칸도 못 지웠고 nvblox 는 대부분 즉시 지움 → '카메라가 볼 때 갱신' 은 nvblox 쪽이 실제로 동작.
- 한계: nvblox 기억은 감쇠(≈ 81 s)·반경 3 m 밖 삭제로 짧음 → '화각 밖에서 오래 기억' 은 못 함. 전역에 nvblox 층을 다시 넣으면 10-01 §8.24 의 유령 칸(통로 입구 93 칸) 문제가 돌아올 수 있음.
- 다음 후보(오프라인, 로버 안 움직임): f2c2·f2d2 순회 bag 의 nvblox 슬라이스로 '전역에 nvblox 를 넣었다면' 통로 유령 칸이 얼마나 생기는지 + 상자 ② 를 계획기가 제때 알았을지 재계산.

## §2 '전역에 nvblox 를 넣었다면' 재계산 — 선언(사용자: 진행, Jetson 192.168.0.101 복귀)
- 자료: 10-07 순회 bag f2c2·f2d2(nvblox 슬라이스·라이다·/map·TF·/plan). PC 에서 rosbags 로(로버 안 움직임).
- 계산 ①(유령 후보): 1 s 마다 nvblox 슬라이스의 장애물 칸(거리 ≤ 0.05 m)을 map 으로 옮겨, (a) 저장 지도에서 벽(점유)으로부터 0.15 m 넘게 떨어진 빈 곳이고 (b) 같은 시각 라이다 점에서 0.10 m 넘게 떨어진 칸 = '카메라만 본 장애물'(낮은 실제 물체 또는 유령). 위치별로 묶어 지속 시간·크기를 나열 → 실제 물체인지 사용자 확인.
- 계산 ②(상자 ② 를 계획기가 알았을 시점): 복귀 목표에서 nvblox 가 상자 ② 자리를 처음 표시한 시각 vs 경로 계획·재계획 시각.
- 판단 규칙(분석 전): 카메라만 본 칸 묶음 중 실제 물체가 아닌 것이 통로(벽 사이 1.0 m 이하) 안에 10 s 넘게 남으면 '전역 nvblox 는 유령 위험 그대로' → 채택 보류. 없으면 전역 nvblox 층 A/B 주행 후보.
