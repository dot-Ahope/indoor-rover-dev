2. **디시메이션 4 유지**: 근거리 한계와 무관(2 로 바꿔도 끊김 거리 동일), 밀도 ×3.7 의 대가가 릴레이 CPU ×2·주기 15→10~12 Hz. 09-09 의 "디시메이션이 최소 거리를 키운다" 가설은 **기각**(측정).
3. **코스트맵의 진짜 근거리 한계는 릴레이 `min_range 0.45`**(유클리드): 0.45 m 안은 0 점, 0.40 m 상자는 왼쪽만·중심선 다리는 0 → 근거리에서 코스트맵 상자가 옆으로 밀리고 정면 얇은 물체가 사라지는 기전. 09-14 에 아티팩트 대책으로 넣은 값이며 오늘 아티팩트는 4 %/0.29~0.35 m.
4. 남는 결정(설정 변경·주행 필요 → 사용자): `min_range` 0.45 → **0.35**(아티팩트 상한 바로 위) A/B 1 회 — 기준: 상자 미관측 최대 시간(dy·cc 24~31 s) 단축, 근거 없는 LETHAL 셀 0 유지, 루프 미달 ≤ 1. 주의: STVL 소거 절두체 `min_z 0.55` 는 그대로라 0.35~0.55 m 의 마킹은 감쇠(120 s)로만 지워진다(09-10 §11 구조 한계, nvblox 가 대체).

## 6. 결정 — min_range A/B 보류, S5 기준선으로 (사용자 질의 "뭐가 더 나은가")
