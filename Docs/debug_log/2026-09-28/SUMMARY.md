## §26 B2 — 회전 데이터로 ICR(회전축 치우침) 식별 (분석 전 선언)
모델: 제자리 회전 중 차체가 차체 좌표의 한 점 p = (px, py) 를 축으로 돈다고 본다. 회전각 θ 뒤 시작 차체 기준 중심 이동 d = (I − R(θ))·p → p = (I − R(θ))⁻¹·d. 회전 중 차체 속도로 쓰면 vx = ω·py, vy = −ω·px(컨디셔너가 휠 vx·vy 에 더할 값). p 는 **회전 방향별**(시계/반시계)로 따로, 속도(0.38/0.20) 의존은 데이터로 확인.
데이터: §3·§4·§5.1·§6 의 스캔 직접 정합 회전 16 회(완전 180°) + R2 부분 회전 1 회(105°, 모델의 회전각 일반화 검사용). 출처 `outputs/j567, j568, j572, j573, j574, j576, j578`.
판정(분석 전):
- **B2-a 설명력**: 방향별 p 로 한 회 빼고 맞추기(leave-one-out) 예측 잔차의 **중앙값 ≤ 0.07 m 그리고 보정 없는 이동 크기 중앙값의 50 % 이하** → 모델 채택.
- **B2-b 속도 의존**: 같은 방향에서 0.20 과 0.38 의 p 차가 잔차 표준편차보다 크면 속도별 p, 아니면 공용.
- **B2-c 각도 일반화**: 105° 부분 회전의 예측 잔차 ≤ 0.07 m.
