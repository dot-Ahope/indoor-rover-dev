### 원인 가림 결과
- **(a) 짧은 lookahead — 확인.** #1 적용으로 선회+직진 코스의 ω 평균 0.086→0.047~0.072, 스파이크 19→5~19(런별 산포 큼), 부호반전 2.4→0~1.1/m. 기하 근거: 헤딩오차 5° 에 대한 ω 응답 = v·2·L·sinθ/L² ∝ 1/L → L 0.20→0.40 이면 절반.
- **(c) 회전→추종 전환각 — 기각.** 0.5→0.25 는 회전↔추종 **모드 채터 6회**(58e 트레이스 12.6~12.9s 에서 v 0.08→0→0.08, ω +0.07→+0.32→+0.10) → 스파이크 28회, 자세오차 −13.8°. 0.5 유지. 0.5 에서 회전 후 ω 는 0.21→0.04 로 4s 에 걸쳐 **단조 감쇠**(58c 7.5~12.5s) — 사용자가 본 "회전 구간 좌우 진동"의 실체는 이 단일 arc 보정 + 격자 경로 시작점 오프셋(횡오차 5~7cm).
- **(d) 위치추정 점프 — 존재, 잔여 원인.** 7회 중 5회에서 map yaw 가 odom 대비 1.6~5.2° 점프(slam 보정). 58a 의 스파이크 4회 중 2회가 점프 직후. 잔여 wander 의 주원인으로 판단.
- **(b) 경로 계단** — 직접 검증 안 함(SmoothPath 미적용). 횡오차 RMS 1.3~3.4cm 로 작아 우선순위 낮음.
- **#4 yaw tol 0.15** — 소요시간 영향 없음(19.2s), 자세오차 상한 8.6° 보장. 채택.

### 채택값 (nav2_params.yaml 반영·배포)
`lookahead_dist 0.40 / min 0.35 / max 0.60 / lookahead_time 2.0`, `rotate_to_heading_min_angle 0.5`(유지), `yaw_goal_tolerance 0.15`.
수용 기준 대비: 부호반전 ≤2/m ✓, 횡오차 RMS <3cm △(1.8~3.4), 회전후 진동 ≤1주기 △(0~2회), 자세오차 <8° ✓, 소요 ±10% ✓.
