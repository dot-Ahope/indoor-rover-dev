prep 이 설치본 링크를 끊던 결함§3

10-15 에 찾은 결함입니다. prep 이 PreferForward 값을 sed -i 로 고칠 때마다 설치본 nav2_params.yaml 이 src 를 가리키는 링크에서 일반 파일로 바뀌었고, 그 뒤로는 src 를 고쳐도 설치본에 반영되지 않았습니다. 그래서 값이 이미 같으면 손대지 않고, 다를 때만 링크를 살린 채 고치게 바꿨습니다.

스크립트
FWD=${FWD:-15.0}
[ -L $Y ] || echo "  ⚠ 설치본 nav2_params.yaml 이 링크가 아님 …"
if ! grep -q "PreferForwardCritic: {enabled: true, cost_power: 1, cost_weight: ${FWD}[,}]" $Y; then
  sed -i --follow-symlinks "s/\(PreferForwardCritic: … cost_weight: \)[0-9.]*/\1${FWD}/" $Y
  echo "  ⚠ PreferForward 를 ${FWD} 로 바꿈(…)"
fi
