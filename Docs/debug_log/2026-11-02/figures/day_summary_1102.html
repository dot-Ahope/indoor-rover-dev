훅 첫 판이 한글 커밋 메시지에서 그냥 통과 (§5)

하려 한 것훅이 stdin 으로 받은 JSON 에서 git commit 명령을 찾기 본 것시험 출력이 깨진 글자 — 콘솔 기본 인코딩(cp949)으로 읽고 있었음 처음 추론출력 표시만의 문제 의심한 이유읽기도 같은 인코딩이면 한글이 든 JSON 이 깨지고, 깨진 JSON 은 '명령 없음' 으로 처리돼 검사 없이 통과한다 스크립트 핵심
# 첫 판 — 콘솔 기본 인코딩으로 읽음. 한글이 든 JSON 이 깨지면 except 로 빠져 cmd = '' → 'git commit 아님' → 통과
try: cmd = (json.load(sys.stdin).get('tool_input') or {}).get('command', '')
except Exception: cmd = ''
# 고친 판 — utf-8 로 읽고, 깨져도 원문 전체에서 git commit 을 찾는다

except Exception: cmd = raw
