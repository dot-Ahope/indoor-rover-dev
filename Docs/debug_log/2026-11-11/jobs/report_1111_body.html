11-11 Smac 구성을 표준으로

어제(11-10) 강제 종료로 bag 을 잃은 f2dm2 를 Jetson 에 남은 노드별 로그로 다시 맞춰 봤고, 사람이 경로를 막았을 때 로버가 어떤 순서로 움직였는지 풀었습니다. 이어서 "어제 설정이 가장 안정적인가" 를 지난 완주 기록과 비교했고, 그 구성으로 반복 시험 f2rr1 을 한 번 돌렸습니다(8/8, 접촉 0). 같은 구성으로 연속 3 회 완주한 기록을 근거로, 사용자 결정에 따라 표준 prep 과 launch 기본값을 Smac Hybrid(실패 시 NavFn) · 재계획 0.01 Hz 로 바꾸고 Jetson 에 배포한 뒤 비공개 원격에 push 했습니다. 판단마다 스크립트 핵심 · 실제 출력 · 저장소 원문 경로를 붙였습니다.
