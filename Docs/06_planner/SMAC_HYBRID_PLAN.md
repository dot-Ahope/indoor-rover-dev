4. Phase P 종료(§7) 뒤 원본 브랜치로 합칠지 · 기본값을 smac 로 바꿀지는 사용자 결정. `TEST_COURSE_AND_GATES.md` 는 Phase P 판을 새로 씀(CLAUDE.md 규칙).

## 4. 오프라인 비교 (로버 안 움직임)

- Jetson 에 **두 번째 planner_server**(ROS_DOMAIN_ID 42, nvblox 재생과 같은 격리)를 띄우고, 기록된 전역 코스트맵(bag `/global_costmap/costmap`)을 그 계획기의 지도로 넣어 `ComputePathToPose(use_start)` 를 NavFn · Smac 각각 호출.
- 입력 장면: 10-22~10-23 bag 의 복귀 접근(상자 보인 뒤, PathBlockedAhead 순간 로버 자리), 서쪽 통로(no5), 문 통과, W3 앞(10-23 §7 의 U 자 경로 자리).
- 지표: 실제 상자 · 통로 벽까지 경로 여유(차체 다각형 기준), 경로 길이, 최대 곡률, 계획 시간, 실패 여부.
- 합격(주행 시험으로 가는 조건): 상자 옆 경로 여유가 NavFn 보다 **≥ 5 cm 큼**(같은 출발 · 같은 지도), 서쪽 통로에서 계획 실패 0, 계획 시간 중앙 ≤ 0.5 s.

## 5. 주행 시험 (Smac, 작업 브랜치)

- 순서: b910 2 회 → no5 1 회 → 사람이 지나가는 b910 1 회(T 시험, 09-29 요구).
- 판정(B0 와 같은 도구): 상자 옆 실제 최소 여유 ≥ 8 cm(2 회 모두), 서쪽 통로 최소 여유 ≥ B0, 계획 실패로 인한 ABORT 0, 출발 차체 충돌 거부 0(있으면 P1 대체 경로가 처리했는지), 짧은 멈칫 · CPU ≤ B0 + 20 %, 목표 시간 ≤ B0 + 15 %.

## 5.1 재계획 주기 — Smac 에서도 기본은 '목표당 1 회 + 막힘 시' (사용자 질문 "smac은 2초에 한번씩 경로 갱신해도 괜찮은지", 10-23)
- 로버 자리에서 다시 그리면 생기는 치우침 누적(10-23 §14)은 계획기와 무관. Smac 은 출발 **방향**까지 받아 그 자세에서 매끄럽게 이어 그리므로 치우침을 그대로 품을 수 있음(추정).
- 2 s 갱신은 좁은 자세(상자 옆 3~5 cm)에서도 계획을 시도하게 함 → Smac 의 출발 차체 충돌 거부(09-15: 1 Hz 재계획 15 회 거부 → 48 s ABORT) 기회가 늘어남.
- 계산: Hybrid-A*(72 방향 단계)는 NavFn 보다 무거움 — 우리 Jetson 에선 미측정(P6). CPU 70 % 에서 2 s 마다면 제어 주기 늦음(멈칫 B)을 키울 수 있음.
- 경로 번갈이(비슷한 비용의 좌/우) 가능성 — 자주 그릴수록 자주 바뀜(추정).
- 장점: 막지는 않는 새 장애물 · 경로 밖 새 물체를 경로에 반영. Smac 은 여유를 계산에 넣으므로 갱신 경로의 질은 NavFn 보다 좋을 것(추정).
- 계획: 기본 = 0.01 Hz + PathBlockedAhead. **A/B 항목**: Smac + 0.5 Hz(지표: `jobs/anal_track_err.py` 경로 이탈 · 상자 옆 여유 · 계획 실패/거부 수 · CPU). 둘의 장점을 함께 얻는 후보 = **기존 경로 위 점에서 이어 그리기**(자동차 스택의 trajectory stitching — 우리 BT 노드 필요, 출발 자세 거부도 피함).

## 8. 2026-10-23 오프라인 비교 첫 판 결과 · 상태: **Hybrid-A* 기준 미달 → 보류, 다음 후보 Smac Lattice(diff)**
- 근거 `Docs/debug_log/2026-10-23/SUMMARY.md` §22(도구 `Docs/tools/plan_offline/`, 재구성 지도 일치 1.0000).
- Hybrid(1.1.20): 상자 옆 차체 여유 NavFn 대비 기본형 −7.1~+0.5 cm, 방향 144 칸형 −1.0~+3.2 cm(기준 +5 미달). cost_penalty 1.2 → 3.0 효과 거의 없음(해석 확장이 경로를 정하는 것으로 추정). 해석 확장 길이 제한(0.5 · 1.0 m)은 즉시 실패 · 'vector::reserve' 예외. 서쪽 통로: 북행 목표 자세가 전역 지도에서 차체 충돌 → 거부, 남행은 경계 통로라 실패(144 칸 + 패딩 0 에선 고리 경로).
- 상자 옆 틈 0.70~0.90 m(가운데면 양옆 18~28 cm)인데 두 계획기 모두 9~16 cm — 꺾임 안쪽으로 짧게 도는 성질은 계획기 종류와 무관.
- 사용자 질문(10-23): "4 륜 구동도 제자리 회전은 되는 것 아닌가?" — 됨. 좌우를 반대로 돌리는 스키드스티어(우리 트랙 차체 포함)는 제자리 회전 가능, 안 되는 것은 조향 바퀴(Ackermann) 차. Hybrid 의 DUBIN 모델은 Ackermann 형 가정이라 우리에겐 불필요한 제약 → 차동 · 스키드스티어용은 Smac **State Lattice**(diff 원형, 제자리 회전 포함). 단 우리 트랙은 제자리 회전 때 미끄러짐이 큼(10-02 회전 중 37 cm, 09-28 180° 당 10~27 cm) — 제자리 회전을 '할 수 있다' 와 '자주 해도 된다' 는 다름.
