# 시험 코스·게이트·주행 절차 — Phase S (STVL 스택) v1.0, 2026-09-21

**적용 범위**: Phase S(현재 스택: STVL + NavFn/SimpleSmoother + MPPI CostCritic)의 "중앙 상자 회피 코스" 주행. 09-11~09-21 에 파편적으로 정한 규칙을 한 곳에 모은 것이며, **근거 날짜의 `Docs/debug_log/<날짜>/SUMMARY.md` 가 원문**이다.
**Phase 전환 규칙**: Phase 가 바뀌면(예: N — nvblox) 이 문서를 그대로 따르지 말고 **절 단위로 검토**해 `v2.0 (Phase N)` 을 새로 쓴다. 코스 기하(§1)와 관찰자·DDS·기록 규칙(§4)은 유지 후보, 게이트 도구(§3)는 지도 계층이 바뀌면 재검토 대상(예: 코스트맵 셀 기준 게이트는 nvblox 층에서 의미가 달라진다).

## 4. 운영 규칙 (게이트가 못 잡는 것)
1. **주행은 사용자의 "시작" 지시로만.** 게이트 통과 = 준비 완료이지 주행 허가가 아니다.
2. 관찰자: 배치 후 카메라 시야 밖·로버 ≥0.30 m. 사람 흔적은 STVL 에 로컬 120 s/전역 180 s 남는다(09-14, 09-18 dy3·dy5).
3. 손으로 로버를 옮기면 반드시 2 단계(prep 재실행). 상자만 옮겼으면 3 단계(클리어 8 s) 후 게이트 재검사면 된다(09-21 cc1 전).
4. 주행 30 s 전 DDS 참여자 생성·소멸 금지(09-21 cc1: 루프 미달 18·EKF 위반 61 → 옮기자 0).
5. 같은 코스 판정은 상자 상대 위치(±6 cm)로 한다. map 원점은 SLAM 보정으로 회차마다 물리적으로 다른 자리가 된다(09-11 s4r3).
6. 판정 기준은 주행 **전에** SUMMARY 에 선언한다(09-17 §12.3, 09-18 §16). 사후 변경은 "정정" 으로 남긴다.
7. 러너 인자 `STAGE`(구성 단계)·`NOTE`(무엇을 바꿨나)·`GIT_HEAD` 필수 — 개선 전후 비교용(09-18 §18).
8. 배치·기록에 쓰는 거리 기준(앞단 / base_link / 카메라)을 문장마다 적는다.
