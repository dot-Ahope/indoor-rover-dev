# 신규 BLDC 모터 (1:90, 45rpm) 교체 — 배선·테스트·자율주행 계획

| 항목 | 값 |
|---|---|
| 문서 ID | ROVER-MOT-003 |
| 작성일 | 2026-08-18 |
| 대상 모터 | 통합 드라이버형 BLDC, DC 12V, 기어비 1:90, 출력축 45 rpm (무부하), 좌/우 2개 모두 교체 |
| 휠 | 기존 Ø40 mm 유지 |
| 상위 문서 | `FIRMWARE_DEV_PLAN.md`, `PROJECT_OVERVIEW.md` |

3번째 모터 교체 (30:1 → 56:1 → **90:1**). 배선 지점은 기존과 동일하므로 작업의
중심은 **펌웨어 파라미터 변경 + 실측 캘리브레이션**이다.

---

## 1. 모터 사양 (판매자 datasheet 기준)

| 선색 | 신호 | 방향 | 사양 |
|---|---|---|---|
| 흑 | GND | IN | 전원 그라운드 |
| 적 | VCC | IN | DC 12V / 24V (전원 직결 — H-브리지 경유 아님) |
| 청 | PWM | IN | 0~5V, VIH≥1.6V=구동, VIL≤1.0V=정지, **최대 50kHz, 권장 15~25kHz** |
| 황 | FG | OUT | 오픈컬렉터, 6 pulse/round(모터축 추정), max 5mA |
| 백 | CW/CCW | IN | VIH≥2.0V=**CCW**, VIL≤0.6V=**CW** |

MCU 3.3V 로직으로 모든 IN 신호 구동 가능 (VIH 최대 요구 2.0V < 3.3V). FG는
오픈컬렉터이므로 3.3V 풀업으로 수신 — 5V 불필요.

### 기존 펌웨어 전제와 다른 점 (핵심)

| 항목 | 기존 (56:1 모터) | 신규 (90:1) | 조치 |
|---|---|---|---|
| PWM 주파수 | **50 Hz** (구모터 실측 확정값) | **20 kHz** (권장 15~25kHz) | `integrated_bldc_driver.c` 타이머 재설정 — ⚠ **2026-09-07 에야 적용** (08-26 교체 후 12일간 50Hz 로 구동됨 → FG 기저 펄스·진동·저속 추종 불량의 원인. `Docs/debug_log/2026-09-07/`) |
| FG 펄스/휠회전 | 215 (실측) | 6×90=**540 추정 — 반드시 실측** | `fg_count_test` 재실행 |
| 최고 속도 | 임시 0.35 m/s | 45rpm × 0.1257m = **0.094 m/s** | `MAX_LINEAR_SPEED_MPS` 하향 |
| 방향선 전진 레벨 | R=HIGH, L=LOW (실측) | CW/CCW 정의 명확 — 장착 방향 따라 재실측 | 램프 테스트로 좌·우 확정 |

⚠ 과거 교훈 (`rover_platform.h` 주석): FG 펄스/모터회전은 datasheet와 다를 수
있음(구모터 6 표기 → 실측 ~3.8). **datasheet 540 값을 코드에 넣지 말고 실측할 것.**

⚠ 속도 트레이드오프: 최고 0.094 m/s는 기존 SLAM 권장 속도(0.2~0.3 m/s)보다
느림. 토크는 크게 향상. 실내 SLAM/Nav2는 가능하나 맵핑 시간이 길어짐 —
Nav2 속도 파라미터를 0.08 m/s 수준으로 설정해야 함.

## 2. 배선 (기존 배선 지점과 동일)

핀 근거: 회로도 1페이지 실측 확인 (2026-08-24, 주석판 PDF `ROVER_JUPITER_R14_배선주석_v2.pdf` 참조),
`FIRMWARE_DEV_PLAN.md §2.3`, `integrated_bldc_driver.h`

| 모터선 | 우측 모터 (M1) | 좌측 모터 (M3) | MCU 넷 | 비고 |
|---|---|---|---|---|
| 청 PWM | **J19 1번핀** | **J19-1 1번핀** | M1A=PC6 / M3A=PA11 | 1K 직렬(R67/R68). 핀순서 1=신호 2=5V(미사용) 3=GND |
| 황 FG | **J15 5번핀(B)** | **J27 5번핀(B)** | H1A=PA15 / H3A=PA0 | 1K 직렬(R4/R76), 풀업은 MCU 내부 |
| 백 CW/CCW | **R3 패드 납땜** | **R74 패드 납땜** | M1B=PC7 / M3B=PA8 | 전용 커넥터 없음. 대안: J15/J27 6번핀(A)=H1B/H3B 사용 + 펌웨어 DIR핀을 PB3/PA1로 변경 |
| 흑 GND | J15 3번핀 또는 전원 GND | J27 3번핀 또는 전원 GND | — | 신호 기준전위 공통 필수 |
| 적 VCC | 12V 라인 (3페이지 전원부) | 12V 라인 | — | ⚠ J15/J27의 4번핀 VCC는 3.3V — 사용 금지 |

⚠ **연결 금지**: J15/J27의 1·2번핀(M+/M−)은 AM2861 H-브리지 출력 — 새 모터의 어떤 선도 연결하지 말 것.

배선 전 필수 확인:
1. **VM 라인 전압 실측** — 12V 확인 (`PROJECT_OVERVIEW.md §10.1` 미해결 항목. AM2861 이슈와 무관하게 신규 모터 VCC로 쓰므로 이번에 실측 확정)
2. **공통 GND** — 모터 GND와 MCU GND가 같은 그라운드인지 도통 확인 (PWM/FG/방향 신호 기준전위)
3. 적/흑 극성 재확인 — datasheet 경고: 오배선 시 모터 소손

## 3. 펌웨어 변경 사항

### 3.1 `integrated_bldc_driver.c` — PWM 20kHz

기존 1MHz tick 유지 시 20kHz에서 duty 분해능이 50 step뿐 → **tick 상향 필수**:

| 타이머 | 클럭 | PSC | ARR | 결과 |
|---|---|---|---|---|
| TIM3 (우, PC6) | 84 MHz | 0 | 4199 | 20 kHz, 4200 step |
| TIM1 (좌, PA11) | 168 MHz | 1 | 4199 | 20 kHz, 4200 step |

duty 0% = 정지 (VIL≤1.0V), deadband(최소 기동 duty)는 램프 테스트로 실측.

### 3.2 방향선 — CW/CCW 레벨 재확정
push-pull 방식 유지 (구모터에서 풀업 부재 이슈로 확정된 방식).
`DIR_RIGHT_FWD_LEVEL` / `DIR_LEFT_FWD_LEVEL`을 램프 테스트 실측으로 재지정.
좌/우 모터는 미러 장착이므로 전진 레벨이 서로 반대일 가능성 높음.
⚠ 주행 중 급반전 금지 — 방향 전환은 duty 0 경유 (통합 컨트롤러 거동 T2에서 확인).

### 3.3 `rover_platform.h`
- `FG_PULSES_PER_REV`: 실측값으로 교체 (T3)
- `MAX_LINEAR_SPEED_MPS`: 램프 실측 후 확정 (예상 ~0.09)
- 휠 상수(Ø40mm)는 유지, 직선 주행 캘리브레이션으로 재검증 (T4)

### 3.4 `f4_pid_test` — PID 재튜닝
기어비/관성/최고속 변경으로 기존 게인 무효. dead-zone feedforward, 적분 클램프,
스톨 감지 윈도우 재조정.

## 4. 단계별 테스트 계획

차체를 받침대에 올려 **바퀴 공중 상태**에서 T1~T3 수행.

| 단계 | 내용 | 사용 도구 | 통과 기준 |
|---|---|---|---|
| **T0** | VM 전압·공통 GND·극성 실측 → 배선 | 멀티미터 | VM=12V±5%, GND 도통 |
| **T1** | PWM 20kHz 펌웨어 수정, 빌드·플래시 | `BUILD_AND_FLASH_GUIDE.md` | 부팅, CLI 응답 |
| **T2** | 개방루프 램프: 방향 레벨 확정, deadband, duty↔속도 선형성, 무부하 최고속 실측, 방향 전환 거동 | `bldc_ramp_test` | 좌/우 전·후진 정상, 최고속 기록 |
| **T3** | FG 캘리브레이션: 20턴 주행 → 펄스/휠회전 실측 (좌/우 각각) | `fg_count_test` | 좌/우 편차 <2%, 값 확정 |
| **T4** | 지상 주행: 직선 1m 실측 → 휠 둘레 보정, 제자리 360° 회전 → wheel base 보정 | 줄자, `/wheel_odom` | 오도메트리 오차 <3% |
| **T5** | 폐루프 PID 재튜닝 (지상, 부하 상태 포함) | `f4_pid_test` | 계단 응답 정착, 발진 없음 |
| **T6** | micro-ROS 재검증: `/cmd_vel` → 주행, `/wheel_odom` 50Hz, watchdog 500ms 정지 | `micro_ros_agent`, teleop | F5c/F6/F8 검증 절차 재통과 |

## 5. 실내 자율주행까지 (T6 이후)

기존 로드맵 Phase 2·3 그대로 진행 — 모터 교체로 달라지는 것은 **속도 파라미터와 URDF**뿐.

### Phase 2 — Jetson ROS2 스택 (`ros2_ws/` 신규 생성, 현재 없음)
1. Jetson: ROS2 Humble 워크스페이스 + `micro_ros_agent` (921600bps~2Mbps, F8 확정값)
2. `rover_description`: `Docs/02_hardware/rover.urdf` 갱신 (Ø40mm 휠 반영 확인) 후 패키지화
3. `robot_localization` EKF: `/wheel_odom` + `/imu/data_raw` → `/odometry/filtered`
4. `rplidar_ros` 통합 (모델 실물 확인 필요 — 미해결 항목), `/scan` 발행
5. `slam_toolbox` 맵핑 — 주행 속도 0.05~0.08 m/s (신규 모터 한계 반영)
6. `rover_bringup` 통합 launch + systemd 등록

### Phase 3 — Nav2
1. Nav2 통합, 코스트맵 파라미터 (로봇 반경 ~0.17m)
2. 속도 제한: `max_vel_x=0.08`, `max_vel_theta≈0.8` (실측 최고속의 85% 이내)
3. 목표점 자율 이동 데모 → 동적 장애물 회피

## 6. 리스크·주의

- **FG 풀업**: STM32 내부 풀업(~40kΩ) 사용 중. FG 최대 주파수 ≈ 405Hz(모터축 4050rpm × 6p)로 낮아 문제 없을 것으로 예상되나, T3에서 펄스 유실 시 외부 4.7~10kΩ → 3.3V 추가
- **duty↔속도 특성**: 통합 컨트롤러가 내부 폐루프(속도제어)인지 단순 전압제어인지 미확인 — T2 선형성 실측으로 판별, PID 구조에 영향
- **저속 한계**: 45rpm 모터의 최저 안정 속도(deadband 상단)가 SLAM 최저 요구 속도보다 높으면 저속 제어성 문제 — T2에서 확인
- **AM2861 스톨 이슈는 본 모터와 무관** (전원 직결, H-브리지 미사용) — 단, 모터 자체 스톨 전류 사양 미확인이므로 12V 라인 퓨즈/전류 확인 권장
