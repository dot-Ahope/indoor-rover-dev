## 9. 용어
- **게이트(A · B · J · C · G2 · P)**: 러너가 출발 직전에 보는 검사. A 중복 프로세스, B 보드 `/wheel_odom` 수신, J nvblox 깊이 주기, C SLAM map→odom 간격 · 지연, G2 출발 자세 여유, P 정지 부하. 하나라도 불합격이면 로버를 움직이지 않는다.
- **`PREP_POSE`**: prep 이 끝날 때 SLAM 이 낸 로버 위치를 비교할 기대 자세. 기본은 출발 테이프 (0, 0, 0°).
- **정지 부하**: 로버가 서 있는 10 s 동안 CPU 코어 전체의 사용률(`/proc/stat` 의 idle · iowait 빼고). 구성(그림자 EKF · SHM · 카메라 모드)에 따라 기준선이 다르다.
- **stamp 지연**: 메시지를 받은 시각 − 메시지 안 시각. map→odom 이 늦게 오면 Nav2 가 좌표 변환에 실패할 수 있다.
- **수명 주기 전이**: Nav2 서버가 unconfigured → inactive → active 로 넘어가는 것. 관리자가 각 서버의 `get_state` 를 물어 확인하며 넘긴다.
- **스크래치패드**: Claude Code 세션의 PC 임시 폴더. 러너 · 비밀번호가 든 파일이 여기 있고, 오래된 파일이 자동으로 지워질 수 있다(추정 — 10-21 · 10-22 · 10-27 세 번).
- **보드 세션**: micro-ROS 펌웨어와 에이전트 사이의 XRCE-DDS 연결. 펌웨어는 리셋 직후 한 번만 만든다 → 에이전트가 새로 뜨면 보드 리셋이 필요(예외 관찰은 §5.2-3).
