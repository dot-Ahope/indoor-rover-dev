## 4. 조치와 효과
- 09-03 시점의 규칙(종합): **직진** = 진행 방향 로버 폭 + 3 cm 밴드 안 점까지의 0.5 백분위 < 8~10 cm 면 정지, 목표 거리 = 그 여유 − 0.35 m. **회전** = 로버 중심 기준 0.5 백분위 < 34 cm(스윕 30 + 4) 면 정지, 시작 전 같은 기준으로 거부. **회전 감속** = 목표 15° 전 ω × 0.35. 주행 전 joy 종료 · EKF/SLAM 초기화(job21a).
- 효과: 좁은 자리(옆 5 cm)에서 1.7 m 직진 완주(09-02), 사각 루프 · 비대칭 측정 전부 가드 오탐 없이 완주.
- 한계: ① 직진 중엔 옆 · 뒤를 안 봄(직진이 휘면 옆이 줄어듦 — 0.2°/m 수준이라 무시했지만 근거는 휨 측정뿐) ② 회전 원의 중심 이동 ③ 가드가 끊은 것과 로버가 반응하지 않은 것이 출력에서 구분되지 않음(job32b) ④ 라이다 최소 감지 0.2 m 와 차체 앞 ~10 cm 사각(09-02 「안전 결함 발견」)은 가드로 해결 불가.
- **이후(09-04 ~): 다음 시기에서 채움** — 포인터: 09-02 저녁부터 주행은 Nav2(코스트맵 · 풋프린트 · inflation)로 옮겨 감([09-02 「Nav2 도입」](../debug_log/2026-09-02/SUMMARY.md)); 펌웨어 스톨 보호 · 자동복구(09-03 오후 작성, 09-07 검증 — CLAUDE.md §2); 러너의 게이트(`Docs/tools/chk_drive_gate.py`, 10-27), `stuck_monitor` · `nav_guard`(09-29, CLAUDE.md §6).

## 8. 도구 해설
공통: 실행 위치 = Jetson. PC WSL 에서 sshpass 로 `/tmp` 에 올려 실행, 모터 구동 스크립트는 사용자가 `!` 로 직접 실행(08-26 「판단·결정」 7). 주행 중 사용자는 로버 옆에서 물리 정지 담당. **2 차 안전 = 펌웨어 `/cmd_vel` 500 ms 워치독**(스크립트가 죽거나 Ctrl-C 되면 지령이 끊겨 모터 정지 — job14d 머리말 'Ctrl-C로 중단(워치독 500ms 정지)'). 정지는 모든 스크립트가 0 Twist 를 10~15 번(약 0.2~0.3 s) 보내는 방식.

풋프린트 실거리 계산(job7d 이후 공통 함수 `clr`/`clearances`): 스캔 점 (r, a) 중 `isfinite & r > 0.05`(일부는 `& r < 12`) → base_link `px = 0.152 + r·cos(a+π)`, `py = r·sin(a+π)` → 직사각형 [−0.25, 0.25] × [−0.165, 0.165] 밖으로 나간 거리 `dx = max(XMIN−px, 0, px−XMAX)`, `dy = max(YMIN−py, 0, py−YMAX)`, `√(dx²+dy²)`. 직사각형 안의 점은 0. 주의: 필터 하한 0.05 m 는 S2L 최소 감지 0.2 m 보다 작아 의미 없는 근접 값이 들어올 수 있음(내 판단, 미검증).

### job20c_pathdrive.sh — 경로 밴드 가드 (09-02)
- 부른 형태: `bash job20c_pathdrive.sh [F|B] [속도=0.06]`. 실행은 F 0.06.
- 상수: `PATH_GUARD = 0.08`, `EMERG = 0.03`(2 차 판에서 미사용), `MARGIN = 0.35`.
- 하는 일:

  4. 정지 후 1.2 s → 휠원시 · odom · slam(map→base, 시작 · 끝 둘 다 있을 때만, 아니면 nan) 이동.

## 9. 용어
- **가드**: 스크립트가 라이다로 장애물 거리를 보다가 문턱 아래면 스스로 정지 지령을 내는 규칙. Nav2 이전 스크립트 주행의 유일한 소프트웨어 충돌 방지.
- **풋프린트 실거리**: 스캔 점에서 로버 외곽 직사각형(0.50 × 0.33 m)까지의 최단 거리. 안에 있으면 0.
- **전역 최소**: 모든 방향의 풋프린트 실거리 중 최솟값. 경로와 무관한 옆 물체에도 반응.
- **각도 섹터**: base_link 기준 각도 범위(예: 전방 ±30°) 안 점만 보는 방식. 옆 물체가 비스듬히 들어옴.
- **경로 밴드**: 진행 방향으로 로버 폭 + 여유(±(YMAX + 3 cm) = ±19.5 cm) 띠 안의 점만 보는 방식 — '지나갈 자리' 만 본다.
- **스윕 반경**: 제자리 회전 때 차체 모서리가 그리는 원의 반지름 = √(0.25² + 0.165²) ≈ 0.30 m(base_link 중심 회전 가정).
- **백분위 가드(0.5 백분위)**: 거리 값들의 최솟값 대신 하위 0.5 % 지점을 쓰는 것. 가짜 점 몇 개를 무시하는 대가로 작은 실물도 무시될 수 있다.
- **ICR(순간 회전 중심)**: [스케일 카드 §9](wheel-odom-scale-slip.md#9-용어). 회전 가드의 원 중심이 이것을 따라 움직인다.
- **detach 실행**: `setsid … </dev/null & disown` 으로 SSH 세션과 분리해 Jetson 에서 끝까지 돌게 하는 것. 끊겨도 가드 · 타임아웃이 계속 집행된다.
- **워치독(500 ms)**: 펌웨어가 `/cmd_vel` 을 500 ms 못 받으면 모터를 즉시 멈추는 안전장치(CLAUDE.md §2). 스크립트가 죽으면 이것이 정지시킨다.
- **회전 감속**: 목표 각 15° 전부터 ω 를 35 % 로 낮춰 정지 지연에 의한 오버슈트를 줄이는 것(09-02, 90° 회전 98~107° → 91~93°).
